# offline_sync_ui

Flutter widgets for sync **job** status — badges, banners, list tiles.

## Install

```yaml
offline_sync_ui:
  git:
    url: https://github.com/LidhinCS/flutter_offline_sync.git
    ref: main
    path: packages/offline_sync_ui
```

Depends on `offline_sync_core` (transitive).

## Key widgets

- `OfflineSyncScope`
- `SyncStatusBadge`, `SyncScreenBanner`, `SyncJobListTile`, `SyncJobsBuilder`

## Guide

[UI widgets](/guide/ui)

## Example

```bash
cd packages/offline_sync_ui/example && flutter run
```
